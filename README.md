# 📸 Full Page Screenshot Pro

### افزونه حرفه‌ای گوگل کروم برای ثبت اسکرین‌شات کامل صفحات وب

**Full Page Screenshot Pro** یک افزونه قدرتمند و پایدار برای Google Chrome است که با استفاده مستقیم از **Chrome DevTools Protocol (CDP)**، امکان ثبت اسکرین‌شات‌های کامل، دقیق و باکیفیت از صفحات وب را فراهم می‌کند.

برخلاف بسیاری از افزونه‌های مشابه که با اسکرول صفحه و چسباندن تصاویر (Stitching) کار می‌کنند، این افزونه مستقیماً از متدهای استاندارد `Page.captureScreenshot` و `Emulation.setDeviceMetricsOverride` استفاده می‌کند تا خروجی نهایی بدون بریدگی، اعوجاج یا افت کیفیت باشد.

---

## ✨ ویژگی‌ها

### 🚀 مبتنی بر Chrome DevTools Protocol (CDP)

- استفاده مستقیم از APIهای رسمی مرورگر Chrome
- بدون نیاز به اسکرول دستی یا اتصال چند تصویر به یکدیگر
- ثبت تصویر توسط موتور رندرینگ مرورگر
- پشتیبانی از `fromSurface: true` برای حداکثر دقت و کیفیت

### 🖼️ خروجی PNG و JPEG

- فرمت PNG با کیفیت کامل (Lossless)
- فرمت JPEG با امکان تنظیم کیفیت بین 50٪ تا 100٪
- مناسب برای مستندسازی، طراحی، QA و تولید محتوا

### 📄 حالت‌های مختلف ثبت تصویر

#### Full Page
- ثبت اسکرین‌شات از کل صفحه
- محاسبه دقیق ابعاد سند با استفاده از `cssContentSize`
- پوشش کامل محتوا از ابتدا تا انتهای صفحه

#### Visible Area
- ثبت سریع تصویر از بخش قابل مشاهده (Viewport)
- مناسب برای تصاویر فوری و سبک

### 📱 ثبت اسکرین‌شات ریسپانسیو

امکان تصویربرداری با اندازه‌های مختلف نمایشگر:

- اندازه فعلی مرورگر
- موبایل (390px - iPhone)
- تبلت (768px - iPad)
- دسکتاپ (1366px)
- عرض سفارشی بر حسب پیکسل

### ⚡ بارگذاری هوشمند محتوای Lazy Load

- اسکرول خودکار قبل از ثبت تصویر
- بارگذاری تصاویر و عناصر دارای `loading="lazy"`
- فعال‌سازی کامپوننت‌های وابسته به اسکرول
- بازگشت خودکار به موقعیت اولیه صفحه

### 📚 پشتیبانی از صفحات بسیار بلند

در صفحات با ارتفاع زیاد، محدودیت‌های پردازشگر گرافیکی ممکن است مانع ثبت یک تصویر واحد شوند.

افزونه به‌صورت هوشمند:

- ارتفاع صفحه را بررسی می‌کند
- در صورت نیاز به حالت چندبخشی (Multi-Part) سوئیچ می‌کند
- فایل‌ها را با نام‌هایی مانند زیر ذخیره می‌کند:

```text
page-part-1.png
page-part-2.png
page-part-3.png
```

- جلوگیری از کرش مرورگر در صفحات بسیار طولانی
- پشتیبانی از صفحات با ارتفاع بیش از 15,000 پیکسل

### 🎨 رابط کاربری فارسی و RTL

- طراحی کاملاً فارسی و راست‌چین
- بدون وابستگی به CDN یا فونت‌های خارجی
- نمایش وضعیت عملیات به‌صورت لحظه‌ای
- مدیریت خطاها با پیام‌های واضح و قابل فهم

## 🛠️ نصب افزونه در Google Chrome

### 1. دانلود پروژه

فایل‌های پروژه را در پوشه‌ای با نام دلخواه (برای مثال `full-page-screenshot-pro`) ذخیره کنید.

### 2. باز کردن صفحه افزونه‌ها

در مرورگر Chrome آدرس زیر را باز کنید:

```text
chrome://extensions
```

### 3. فعال‌سازی Developer Mode

از گوشه بالا سمت راست صفحه، گزینه **Developer mode** را فعال کنید.

### 4. بارگذاری افزونه

روی دکمه **Load unpacked** کلیک کنید.

### 5. انتخاب پوشه پروژه

پوشه‌ای را انتخاب کنید که فایل `manifest.json` در آن قرار دارد.

### 6. شروع استفاده

پس از نصب، آیکون افزونه را از بخش Extensions به نوار ابزار مرورگر **Pin** کنید و از آن استفاده نمایید.
